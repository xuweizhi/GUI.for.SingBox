# 上游 v1.26.1 合并实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将 `gui-for-cores/main` 的 `v1.26.1` 完整合入本地 `main`，保留全部本地 WebUI、backend worker、节点控制、节点测速和 systemd 行为。

**架构：** 使用非快进 merge 保留上游拓扑。冲突按依赖顺序处理：先建立合并状态，再解决 manifest 和类型契约，然后处理 modal/UI 与 worker 业务逻辑，最后从最终 manifest 重生成派生依赖文件并执行完整验证。

**技术栈：** Git、Go 1.25、Wails 2、Vue 3、Pinia、TypeScript、Vitest、pnpm 10、systemd。

---

## 文件结构

- `frontend/.env`：桌面构建版本和运行时标识。
- `frontend/package.json`、`frontend/pnpm-lock.yaml`：前端脚本、直接依赖和可复现依赖图。
- `frontend/src/components/Modal/index.vue`、`frontend/src/utils/interaction.ts`：模态框状态机、动态容器和销毁契约。
- `frontend/src/components/_common/AppShell.vue`、`GlobalOverlays.vue`、`NavigationBar.vue`：应用壳层、全局浮层和 WebUI 导航行为。
- `frontend/src/stores/app.ts`：About modal 和最小化列表状态。
- `frontend/src/views/HomeView/components/OverView.vue`：首页统计、当前节点和上游样式钩子。
- `frontend/src/stores/scheduledtasks.ts`：backend worker 与前端 Cron 调度归属。
- `frontend/src/types/app.d.ts`：全局类型、本地模块导出和插件可见声明。
- `frontend/src/utils/generator.ts`：direct inbound 与 DNS 配置生成。
- `go.mod`、`go.sum`：Go 直接依赖和最终模块图。
- `frontend/src/components/__tests__/modal.spec.ts`、`frontend/src/stores/__tests__/scheduledtasks.spec.ts`、`frontend/src/utils/__tests__/generator.spec.ts`：冲突行为回归验证。
