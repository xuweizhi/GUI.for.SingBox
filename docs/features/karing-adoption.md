# 节点筛选、订阅 DNS、Endpoint 与前置代理

本次功能基于 Karing 2026 年 9—10 月的功能变化，按本项目的服务端 WebUI 架构实现。

## 动态节点组按字段匹配

在「节点分组」中编辑动态分组，选择匹配字段：

- 综合：订阅名、节点名、协议拼接后匹配，保留旧配置行为。
- 节点名称：仅匹配节点名称，例如 `香港|HK`。
- 协议：仅匹配协议，例如 `^(vless|hysteria2)$`。
- 来源订阅：仅匹配订阅名称。

包含和排除正则都作用于所选字段。成员预览展示实际匹配值与命中原因；订阅范围、禁用状态和最大节点数仍共同生效。

## 订阅节点 DNS

在订阅编辑窗口启用「使用订阅 DNS 解析节点域名」。默认关闭，旧订阅继续使用配置中的默认节点解析器。

支持从 sing-box JSON 的 DNS 服务器与默认解析器，以及 Clash 的 `dns.proxy-server-nameserver` 提取节点 DNS 信息。可以手动指定 DNS 地址，手动配置优先于订阅提供的值。地址支持 IP、`local`、`udp://`、`tcp://`、`tls://`、`quic://`、`https://` 和 `h3://`。手动列表使用首项；其余地址保留，不表示自动故障切换。

每个订阅的 DNS 标签独立生成，引用的 bootstrap DNS 和代理依赖同步处理，不导入订阅中的网站 DNS 分流规则。订阅刷新保留用户开关与手动覆盖，更新提供方 DNS。若配置有循环引用或缺失依赖，会显示错误，不会静默改成直连。

「网络检测」的节点诊断读取当前运行配置，展示节点解析器、Endpoint 类型与前置代理路径。若节点通过前置代理拨号，会明确显示该关系，不把被忽略的本地 DNS 字段当作实际解析器。

## Endpoint 导入与编辑

订阅 JSON 可以同时包含 `outbounds` 和 `endpoints`，也可以只包含 `endpoints`。Endpoint 与普通节点一样可加入节点组和策略组，节点列表会显示 Endpoint 标记。

节点编辑器采用标准的 `outbounds` / `endpoints` JSON 结构，保留 WireGuard peers、密钥、协议扩展字段与 DNS 数据。缓存内部类型标记不会写入核心配置。未知类型也会保留，最终是否支持由用户选择的实际 sing-box 核心校验；失败提示包含对应节点与处理建议。

编辑完整生成配置时，未改变节点/DNS 依赖的编辑保留原来的订阅、节点组和前置代理关联。若直接修改这些生成内容，将保留修改后的原生节点数据和实际代理链，避免下次生成时恢复成旧订阅值。

## 策略组前置代理

在配置的策略组编辑窗口设置「前置代理」，可选择另一个手动或自动选择策略组。其语义为：

```text
本机 → 前置策略当前节点 → 本策略选中的落地节点 → 目标
```

节点组负责成员来源，策略组负责前置代理。前置引用使用稳定 ID，重命名不会断开引用；仍被使用的前置组不能直接删除。成员引用与前置引用一起执行循环检测。

配置生成会为不同链路创建独立实例，同一节点可以同时用于直接连接和不同前置代理。嵌套策略组保持相同语义，自动选优的探测作用于生成后的完整代理链。

直连、阻断等不支持前置代理的成员会被明确拒绝。需要多个运行实例的有状态 Endpoint、系统 WireGuard 网卡或固定监听端口可能发生冲突，此时需为各链路配置独立 Endpoint；普通用户态 WireGuard Endpoint 可生成独立链路实例。

## 验证与核心兼容性

启动时先使用所选核心执行 `sing-box check`，通过后才替换运行配置。失败保留已有配置文件，并给出核心原始错误与节点上下文。

前端测试：

```bash
cd frontend
npm test
npm run build
```

可选的真实核心配置测试使用本机二进制，不下载核心，也不修改生产服务：

```bash
SING_BOX_TEST_BINARIES=/absolute/path/to/sing-box npm test -- src/utils/__tests__/generatorCoreCompatibility.spec.ts
```

Linux 下可使用冒号分隔多个二进制路径，以验证不同核心版本。

真实链路测试会临时启动本地 SOCKS 中转、落地代理、HTTP 目标和核心进程，验证普通请求及自动测速探测均经过完整链路，结束后清理进程和临时目录。运行环境需要允许绑定本地端口：

```bash
SING_BOX_TEST_BINARIES=/absolute/path/to/sing-box npm test -- src/utils/__tests__/generatorChainTraffic.spec.ts
```
